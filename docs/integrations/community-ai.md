# Community delegated AI (preview)
Dedicated registered Community client, explicit ai.infer consent, MCP audience, live consent, account ACL, AI subscription and current model settings. The endpoint is disabled unless GSW_COMMUNITY_AI_ENABLED=true and GSW_COMMUNITY_OAUTH_CLIENT_ID matches the registered client. POST /integrations/community/v1/chat accepts accountId and bounded user/assistant turns. Read-only tools are separately authorized and bounded; no writes or sends. This is an isolated conversational adapter to the native GSW provider and registry, not yet the persistent native chat/confirmation engine. Do not enable until tests, real OAuth and cross-account checks pass. Rate limit is the existing Fastify per-IP limiter; per-user quota and durable chat history remain follow-up work.
## Manual compose preview
Separately disabled by default: GSW_COMMUNITY_SEND_ENABLED=true and GSW_COMMUNITY_REVIEW_KEY (64 hex characters, dedicated secret). The registered Community client must receive mail.send, templates.read and signatures.read. Review returns the native sender, rendered plain text, current default template and signature state; the signed review expires in ten minutes and binds the authorized identity/account, recipient, subject and full native rendering. The manual send endpoint accepts only a single recipient and confirmed review, rechecks live consent and mailbox permissions, and uses the native outbound reservation with a stable review ID. AI cannot invoke either endpoint. A queued status is not delivery. Attachments, reply composition, explicit template overrides, HTML preview and campaign delivery remain follow-up work. Do not enable without staging tests of actual sender identity, template/signature, Sent folder and retries.
